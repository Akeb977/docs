# Order Confirmation Email

Send immediately after purchase to confirm the order and set delivery expectations.

## Template Specifications

| Property | Value |
|----------|-------|
| Template Type | Transactional |
| Layout | Single column with product list |
| Primary CTA | Track Order / View Order |
| Send Trigger | Immediately after purchase |
| Open Rate | 60-70% (highest of all email types) |

---

## Email Copy Structure

<Accordion title="Subject Line">
  ```
  ✅ Order Confirmed - #[ORDER_NUMBER]
  Thanks for your order! Here's what's next
  Order #[ORDER_NUMBER] is confirmed
  ```
</Accordion>

<Accordion title="Content Sections">
  ```
  1. Thank you message
  2. Order number & date
  3. Estimated delivery date
  4. Order items with images
  5. Billing/shipping address
  6. Order total
  7. Customer support info
  8. Cross-sell recommendations (optional)
  ```
</Accordion>

## Dynamic Variables

Replace these with your e-commerce platform's merge tags:

| Variable | Example | Description |
|----------|---------|-------------|
| {{ORDER_NUMBER}} | #ORD-12345 | Unique order ID |
| {{ORDER_DATE}} | Nov 18, 2024 | Purchase date |
| {{DELIVERY_DATE}} | Nov 22-25, 2024 | Estimated delivery |
| {{CUSTOMER_NAME}} | John Doe | Customer name |
| {{PRODUCT_IMAGE_URL}} | https://... | Product image |
| {{TRACKING_LINK}} | https://... | Order tracking URL |

## Best Practices

<Tip>
  **Send Immediately**: Customers expect this email within seconds of purchase
</Tip>

<Warning>
  **Include All Details**: Order number, items, total, and shipping info are essential
</Warning>

<Tip>
  **Cross-sell Opportunity**: Add a "You might also like" section (but keep it subtle)
</Tip>
