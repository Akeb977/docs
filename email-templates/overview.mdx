## Key Features

- **Responsive Design**: All templates work perfectly on mobile and desktop
- **HTML/CSS Ready**: Production-ready code with inline CSS for email clients
- **Figma Compatible**: HTML structure designed for easy Figma import and editing
- **Conversion Optimized**: Clear CTAs and proven layouts
- **Brand Customizable**: Easy to adapt colors, fonts, and imagery

## Using These Templates

### 1. Review the Design
Browse the template documentation to see previews and specifications.

### 2. Access the HTML
Each template includes clean, commented HTML code with inline CSS.

### 3. Customize in Figma
Import the HTML or use it as a reference to recreate designs in Figma for client presentations.

### 4. Deploy
Use the HTML directly in your email service provider (Mailchimp, Klaviyo, Sendgrid, etc.).

## Technical Specifications

- **Max Width**: 600px (email standard)
- **Responsive Breakpoints**: Mobile (<480px), Desktop (≥600px)
- **CSS**: Inline styles for maximum compatibility
- **Image Format**: Optimized JPG/PNG with fallbacks
- **Testing**: Compatible with Gmail, Outlook, Apple Mail, Yahoo, etc.
