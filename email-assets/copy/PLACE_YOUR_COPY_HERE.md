# Save Your Email Copy Here

Store finalized email copy for each template in plain text or markdown files.

## File Naming Convention

Match your template names for easy reference:

```
welcome-email-copy.txt
order-confirmation-copy.txt
abandoned-cart-email-1-copy.txt
abandoned-cart-email-2-copy.txt
sale-announcement-copy.txt
```

## Copy Document Structure

Each copy file should include:

### 1. Subject Line Options
```
Subject Line A: Welcome to [Brand]! Here's 15% off
Subject Line B: You're in! Let's get started
Subject Line C: Thanks for joining - here's a gift 🎁
```

### 2. Preheader Text
```
Preheader: Your special welcome gift is waiting inside →
```

### 3. Email Body Copy
```
HEADLINE: Welcome to the Family!

SUBHEADLINE: We're thrilled to have you here.

BODY:
At [Brand Name], we believe in [value proposition].
Explore our collection and discover your new favorites.

[Continue with full copy...]
```

### 4. Call-to-Action (CTA)
```
Primary CTA: Shop Now
Secondary CTA: Learn More
```

### 5. Footer Copy
```
Need help? Contact us at support@brand.com
Follow us: @brandname

© 2024 Brand Name. All rights reserved.
123 Street Name, City, State 12345
```

## Best Practices

### Subject Lines
- Keep under 50 characters
- Front-load important words
- Test with/without emojis
- Personalize when possible: "{{FirstName}}, ..."
- Avoid spam trigger words

### Preheader Text
- 85-100 characters optimal
- Complements subject line (doesn't repeat it)
- Includes call-to-action preview
- Works with subject as complete thought

### Body Copy
- **Short paragraphs** (2-3 sentences max)
- **Scannable** with headers and bullets
- **Clear hierarchy** (H1 → H2 → Body)
- **One clear CTA** per email
- **Mobile-friendly** (keep it concise)

### CTA Copy
- **Action-oriented**: "Shop Now", "Get Started", "Claim Offer"
- **Create urgency**: "Shop Today", "Limited Time"
- **Be specific**: "Shop Women's Sale" vs "Click Here"

## Version Control

Track copy revisions:

```
welcome-email-copy-v1.txt    # Original
welcome-email-copy-v2.txt    # After A/B test
welcome-email-copy-final.txt # Final approved version
```

Or use dates:
```
welcome-email-copy-2024-11-18.txt
```

## Personalization Variables

Mark dynamic content clearly:

```
Hi {{FirstName}},

Your order #{{OrderNumber}} is confirmed!

Thanks for your purchase on {{OrderDate}}.
```

## Copy Checklist

Before finalizing copy:

- [ ] Subject line under 50 characters
- [ ] Preheader 85-100 characters
- [ ] Body copy is scannable
- [ ] Single clear CTA
- [ ] Personalization variables marked
- [ ] Spell-checked and proofread
- [ ] Brand voice consistent
- [ ] Mobile-friendly (short sentences)
- [ ] No spam trigger words
- [ ] Legal requirements met (if applicable)

## A/B Testing Ideas

Track variations to test:

```
SUBJECT LINE A/B TEST:
Version A: "Flash Sale: 50% Off Everything"
Version B: "50% Off Ends Tonight - Don't Miss Out"

HEADLINE A/B TEST:
Version A: "Your Cart Is Waiting"
Version B: "Complete Your Order & Save 10%"
```

## Spam Trigger Words to Avoid

- Free, Winner, Prize, Congratulations
- Click here, Act now, Limited time
- $$$, 100% free, No cost
- All caps subject lines
- Excessive exclamation marks!!!

## Copy Length Guidelines

| Email Type | Subject | Body | Total Words |
|------------|---------|------|-------------|
| Welcome | 30-50 chars | 75-150 words | Short |
| Transactional | 40-60 chars | 50-100 words | Very short |
| Promotional | 30-50 chars | 100-200 words | Medium |
| Abandoned Cart | 30-50 chars | 75-125 words | Short |
