# Upload Your Email Design References Here

Place your email template reference/inspiration images in this folder.

## File Naming Convention

Use descriptive names that match your template:

```
welcome-email-reference.png
order-confirmation-reference.png
abandoned-cart-reference.png
sale-announcement-reference.png
shipping-notification-reference.png
```

## Supported Formats

- PNG (recommended for screenshots)
- JPG
- PDF (if design mockups)

## Purpose

These reference images help you:
1. Document your design vision
2. Share inspiration with team/clients
3. Reference when coding the HTML
4. Include in documentation pages

## How to Use

After uploading a reference image:

1. Update the corresponding template .mdx file
2. Add an image tag like this:

```mdx
<img src="/email-assets/reference-images/welcome-email-reference.png" alt="Welcome Email Design Reference" />
```

## Examples

Your reference images might include:
- Screenshots of emails you like
- Design mockups from Figma/Sketch
- Client-provided inspiration
- Competitor email examples
- Brand guideline references

---

**Tip**: Keep file sizes reasonable (<2MB) since they'll be displayed in documentation.
